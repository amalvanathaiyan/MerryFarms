Merry Farms, built so any farm can run its own shop on it.

Merry Farms is the first farm on a shared platform. Each farm gets its own shop link, WhatsApp number, products, delivery slots and customers, kept apart from every other farm. You run the whole platform from one admin panel, the same way Hotelier-4U works for hotels.

  1. Pick a farm in the bar below. Each one is a separate tenant with its own data.
  2. Farm phone, Catalogue: add a product or change a price. It appears in the customer's shop and WhatsApp menu straight away.
  3. Farm phone, Settings: add or edit a delivery slot (days, cut-off time, max orders). Then check the customer's checkout.
  4. Open Platform admin to onboard a new farm, then open its apps.

One app, many farms

Every record carries the farm's ID, and database rules stop one farm from ever seeing another's orders or customers. Each farm gets its own link, such as merryfarms.farmforyou.in.

Per farm

Their own WhatsApp number

Each farm connects its own WhatsApp Business number, so customers chat with the farm they know. A farm can start with only the web shop and connect WhatsApp later.

Platform

Plans, trials and support

The platform admin onboards farms from a starter catalogue, runs free trials, tracks monthly revenue, and can pause a farm that stops paying.
